## 本批已落地（代码）

- 浅/深色主窗背景与卡片色板（`DesignTokens`）
- D2 暖色主操作按钮文案统一为 **「复扫查看变化」**（`#9C4F39`）
- 青蓝选中 Tab（`#97C5D1` / `#25344A`）；五摘要卡 + 五 Tab + 表格
- 次级描边「停止监控」；既有状态条（失败/陈旧结果/采样中/覆盖缺口）保留
- 独立「取消扫描」与停止监控并存（既有能力，未改机制）
- 窗口：`defaultSize` 建议布局；**未**按组件板硬加 1368×872 最低限制（仅软下限 720×480 保可用性）
- 字体：系统 SF / PingFang（`.system`），卡片数值 `monospacedDigit`
- 包内默认 `marketing_version=0.1.1`；目标 Release/tag 约定 **`v0.1.1-beta.1`**（本批不自动发布）
